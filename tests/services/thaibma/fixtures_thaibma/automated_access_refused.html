ไม่อนุญาตให้ดึงข้อมูลด้วยโปรแกรมอัตโนมัติ

เว็บไซต์ www.thaibma.or.th ให้บริการสำหรับการเข้าชมผ่านหน้าเว็บด้วยเบราว์เซอร์เท่านั้น ไม่อนุญาตให้ใช้โปรแกรม สคริปต์ หรือเครื่องมืออัตโนมัติดึงข้อมูลจากเว็บไซต์ หากต้องการใช้ข้อมูลแบบเชื่อมต่อระบบ กรุณาใช้บริการ ThaiBMA API ที่ https://apiportal.thaibma.or.th หรือติดต่อสมาคมตลาดตราสารหนี้ไทย

Automated access is not permitted

www.thaibma.or.th is provided for viewing through a web browser only. Programs, scripts and other automated tools that retrieve data from this website are not permitted. For system-to-system access to data, please use the ThaiBMA API service at https://apiportal.thaibma.or.th or contact the Thai Bond Market Association.
